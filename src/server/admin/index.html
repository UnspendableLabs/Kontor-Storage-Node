Reset the database

Deletes every agreement and challenge this node holds. Intended for when the Kontor signet has been reset and the node's state refers to a chain that no longer exists: the daemon then re-fetches agreements from the Portal from scratch.

Preserved: the BLS key, the daemon lock and everything else in the storage directory — only blobs named by the rows being deleted are removed, and only if you ask. Downloads already in flight may write a file back after the wipe; a node restart afterwards is the clean way to be sure.
